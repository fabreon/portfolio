# Portfolio — Web制作 / 業務自動化

AIを使って、小さな仕事を速く・丁寧に。Web制作（ランディングページ）と業務自動化ツールの制作実績をまとめた、自己紹介・作品ショーケースサイト。

## 🎨 デザイン

- **ミニマル・テック / 完全モノクロ** — タイポグラフィと余白で見せるエディトリアルな構成
- 作品スクショの色を引き立てるため、サイト本体は無彩色で中立に
- フォント: Inter / JetBrains Mono / Noto Sans JP

## 🛠 技術スタック

- HTML / CSS / 一部 JavaScript（Vanilla、フレームワーク非依存）
- レスポンシブ対応・SEO/OGP・アクセシビリティ配慮（フォーカス可視化・見出し階層・代替テキスト）

## 📁 構成

```
portfolio-site-v3/
├── index.html          # トップ（Hero / About / Skills / Works / Footer）
├── style.css           # モノクロ・ミニマルのスタイル
├── works/
│   └── excel.html      # 作品詳細ページ（EC受注データ統合ツール）
├── images/             # 作品スクショ・OGP画像
└── favicon.svg
```

## 🌟 掲載作品

- **Pop Bloom** — Y2K maximalism のLP（Vanilla / AI画像生成）
- **Morning Hill** — 朝活カフェのLP（クラフト / OGP・JSON-LD）
- **EC受注データ統合ツール** — 複数ECの受注CSVを統合・集計する業務自動化ツール（Python / Streamlit）
