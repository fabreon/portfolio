業務自動化ツール

EC受注データ統合・集計ツール

複数ECの受注CSV（楽天・Amazon・自社BASE 等）を、
ドラッグ&ドロップで統合・集計・グラフ化して、Excel で出力。
月末の集計作業「2時間 → 数秒」を実現します。

01

概要

下記のような場面を想像して制作しました。

誰のため
副業でEC運営をしている個人事業主の方。
例として、ハンドメイドアクセサリーを楽天・Amazon・自社BASEの3チャネルで販売する想定で設計しました。
解決する問題
各ECの受注CSVは列名がバラバラ（注文日 / purchase-date / order_date …）。
毎月それを手作業で揃えて統合・集計していた「月末2時間」を、数秒に短縮します。
主な機能
  • ファイル名・列名からプラットフォームを自動判別
  • 類義語辞書で列マッピングを自動推測
  • 商品別・プラットフォーム別・日別の集計をグラフ付き Excel で出力
  • 対応プラットフォームの追加・編集をブラウザ内で完結（設定UI内蔵）
技術
Python / Streamlit / pandas / openpyxl / matplotlib / plotly。
データはお使いのPC内だけで処理し、クラウドには送信しません。

※ ペルソナ（田中さん）やサンプルデータは、ポートフォリオ用に想定した架空のものです。ツールそのものは実際に動作します。
